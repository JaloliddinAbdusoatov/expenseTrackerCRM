# PDF fonts (optional)

Place TTF/OTF fonts here so reports export in the selected language without transliteration:

- **Russian & English:** `Roboto-Regular.ttf` or `NotoSans-Regular.ttf` (download from Google Fonts)
- **Japanese:** `NotoSansJP-Regular.otf` or `NotoSansJP-Regular.ttf` (e.g. from [typeface-notosans-jp](https://www.npmjs.com/package/typeface-notosans-jp) or Google Fonts)

If no font is found, the backend uses Helvetica and transliterates Cyrillic to Latin (no errors).
