進捗を素早く可視化

ビジュアルレポートと目標管理で、お金の習慣を改善できます。

🧠 解決する課題

  • 多くのユーザーは支出を記録しますが、浪費の原因までは把握できていません。
  • 従来の家計簿は数字中心で、行動の文脈が見えにくいです。
  • 予算管理、モチベーション、レポート機能が別々のツールに分散しがちです。

⚡ 私たちの解決策

  • 感情と財務の分析を組み合わせ、数字の背後にある支出パターンを可視化します。
  • AIアシスタントが個別インサイト、提案、素早い操作を提供します。
  • 目標、チャレンジ、レポートを1つのプラットフォームに統合します。

主要機能

AIチャットアシスタント

個別の金融インサイトと実行しやすい次の一手を提案します。

感情分析

喜び・中立・悲しみによる支出傾向を時系列で可視化します。

目標と予算

上限設定、進捗追跡、計画の継続をサポートします。

チャレンジと実績

ゲーミフィケーションとランキングで継続的な動機づけを高めます。

スマートレポート

分析や共有に使えるPDF/Excel/HTMLレポートを出力します。

多言語対応

複数言語をサポートし、より広いユーザーに使いやすくします。

技術スタック

  • React + TypeScript + Vite
  • NestJS + TypeORM
  • SQLite（MVP）、拡張可能なDB構成
  • Gemini AI連携
  • レート制限、バリデーション、モニタリング

プロダクトロードマップ

  • 本番向けのセキュリティと認証を強化。
  • 同時接続ユーザー増加に備えてデータ層を拡張。
  • モバイル中心の体験と通知機能を拡充。
  • AIによる支出予測と節約プランを導入。

期待される効果

EmotionFlowは、受動的な記録から能動的な意思決定へとユーザーを導きます。財務データに感情の文脈とAIガイダンスを組み合わせることで、個人や家族の気づき、継続性、そして長期的な金銭習慣を高めます。
